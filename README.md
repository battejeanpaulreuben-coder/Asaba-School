## 📌 About the Project

This is a fully functional, multi-page website designed and developed for **Asaba School Masindi** — a Nursery and Primary School established in **1990**, located on Ashton Drive, P.O. Box 438, Masindi, Uganda.

The website simulates a professional online presence for the school, showcasing its programs, facilities, gallery, staff, and providing a contact/registration portal for prospective parents.

## 📄 Pages & Key Features

### 1. 🏠 Home (`index.html`)
- Announcement ticker with live school news
- Hero banner with call-to-action buttons
- Animated statistics counter (students, teachers, years of excellence)
- Image slideshow of school activities
- Why Choose Asaba highlights section
- Latest news/events cards

### 2. ℹ️ About (`about.html`)
- School history and mission/vision statements
- Core values section
- Head Teacher and Deputy Head Teacher profiles
- Teaching staff overview

### 3. 📚 Academics (`academics.html`)
- Nursery and Primary curriculum breakdown
- Subject listing table
- Timetable structure
- Co-curricular activities overview
- PLE results showcase

### 4. 🖼️ Gallery (`gallery.html`)
- Responsive photo grid with 24 school images
- Interactive lightbox for full-size image viewing
- Category filters (Academics, Sports, Events, Culture)

### 5. 📬 Contact & Registration (`contact.html`)
- Contact information cards (address, phone, email, hours)
- Embedded Google Maps location reference
- Contact enquiry form with JavaScript validation
- Student registration/admission interest form

## ⚡ JavaScript Features Implemented

1. **Hamburger / Mobile Navigation** — Toggle menu open/close on small screens
2. **Scroll-to-Top Button** — Appears on scroll; smooth scrolls back to top
3. **Image Slideshow** — Auto-advancing with manual prev/next controls and dot indicators
4. **Animated Counters** — Statistics count up when scrolled into view
5. **Gallery Lightbox** — Click any gallery image to view it in a full-screen overlay
6. **Form Validation** — Contact and registration forms validate required fields, email format, and phone numbers before submission; displays user-friendly error messages

## 📱 Responsive Design

The website is fully responsive across all screen sizes:

| Breakpoint | Layout |
|---|---|
| **Desktop** (> 900px) | Full navigation, multi-column grids |
| **Tablet** (600–900px) | Collapsed nav, 2-column grids |
| **Mobile** (< 600px) | Hamburger menu, single-column stacked layout |

## 🚀 Deployment

This site is hosted for free on **GitHub Pages**.

### How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/asaba-school.git
   ```
2. Open `index.html` in any modern web browser — no build tools or server required.

### How to Deploy on GitHub Pages

1. Push all files to a GitHub repository
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)` folder
4. Click **Save** — your site will be live at `https://yourusername.github.io/asaba-school`

## 📝 Challenges & Lessons Learned

**Challenges faced:**
- Making the gallery grid fully responsive while keeping consistent image proportions
- Implementing the slideshow auto-advance and syncing it with dot indicators
- Ensuring form validation gives clear, helpful feedback without page reloads

**Lessons learned:**
- CSS Grid and Flexbox complement each other — Grid for overall page structure, Flexbox for component-level alignment
- JavaScript event delegation makes managing many elements much more efficient
- Testing on real mobile devices reveals layout issues that browser DevTools sometimes miss
